# 서류 업무 (document-prep)

## 1. 필요서류 목록

| No | 서류명 | 발급처 | 고객 준비 / 사무실 작성 | 근거(출처·기준일) | 상태 |
|---|---|---|---|---|---|

- 상태: `준비 필요` / `제출됨(가상)` / `해당 여부 확인 필요`
- 공식 목록을 확인하지 못한 서류는 근거란에 `[확인 필요]`.

## 2. 신청서·사유서 초안

- 초안 맨 위에 **"초안 — 대표 행정사 검토 전, 제출 금지"** 를 표시한다.
- case-info.md 에 있는 사실만 사용한다. 모르는 칸은 `{{입력 필요: 항목명}}` 으로 남긴다.
- 사유서는 ① 신청인 소개 ② 체류 경과 ③ 신청 사유 ④ 요건 충족 내용 ⑤ 향후 계획 순으로 짧게 작성한다.

## 3. 번역

- 요청이 있을 때만 수행. 원문과 번역문을 나란히 두고 "AI 번역 초안 — 공증·전문 번역 대체 불가"를 표시한다.
- 고객 안내문은 필요 시 고객 모국어(예: 베트남어) 요약본을 함께 작성할 수 있다.

## 4. 누락·오류 검증

- 고객정보 ↔ 서류 목록 ↔ 초안 내용의 이름·날짜·체류자격·금액이 서로 일치하는지 확인한다.
- 유효기간이 있는 서류(발급 후 기간 제한 등)는 기준을 확인했을 때만 적고, 아니면 `[확인 필요]`.
- 발견한 문제를 "누락/오류 목록"으로 정리한다.
