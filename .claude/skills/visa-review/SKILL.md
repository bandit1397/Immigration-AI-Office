# 체류자격 검토 (visa-review)

## 1. 고객정보 분석

case-info.md 에서 아래 항목을 표로 정리하고, 비어 있거나 모호한 항목은 "추가 필요정보"로 분류한다.

- 국적, 나이, 현재 체류자격, 체류기간(입국일·만료일), 직장/소득, 학력, 한국어능력, 사회통합프로그램 이수, 가족관계, 범법·체납·출입국 위반 이력, 희망 체류자격, 희망 일정

## 2. 요건 검토

1. 희망 체류자격의 요건을 **공식 자료로 확인**한다 (`legal-research` Skill 사용).
2. 요건을 항목별 표로 만든다:

| 요건 | 기준(출처·기준일) | 고객 해당 내용 | 판단 | 비고 |
|---|---|---|---|---|
| 예: 체류기간 | … | 4년 | 충족/미충족/판단 불가 | |

3. 점수제 자격이면 항목별 점수를 계산하되, 점수표를 공식 출처에서 확인하지 못했으면 점수를 적지 말고 `[확인 필요]` 로 둔다.
4. 계산 과정을 보여 준다 (사무장이 검산할 수 있도록).

## 3. 신청 가능성 및 위험요소

- 종합 판단: `가능성 높음 / 보통 / 낮음 / 판단 불가` 중 하나 + 근거 3줄 이내
- 위험요소: 불허 가능 사유, 서류 미비, 기간·시기 문제, 소득 증빙 문제 등
- 대안: 요건 미충족 시 고려할 다른 체류자격이나 보완 방법 (확인된 범위에서만)

## 금지

- "반드시 허가됩니다" 등 확정적 표현
- 출처 없는 기준 수치 제시
